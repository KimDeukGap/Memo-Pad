# Mem-Pad
떠오르는 아이디어나 간단한 메모를 터미널에서 빠르고 가볍게 작성하고 관리할 수 있는 초간단 파이썬 스크립트입니다.
로컬 환경에서 텍스트 기반으로 편리하게 노트를 남길 수 있습니다.

기능
- 저장된 메모 전체 목록 조회
- 새로운 메모 작성 및 추가
- 불필요한 메모 번호 선택 삭제
- JSON 파일을 통한 데이터 자동 저장

설치 및 실행 방법
1. 레포지토리 클론 git clone https://github.com/username/MemoPad.git cd MemoPad
2. 스크립트 실행 Bash셸 -> python memo.py
3. 입력값
- 메뉴 선택 (1: 메모 목록, 2: 메모 작성, 3: 메모 삭제, 4: 종료)
- 메모 내용 또는 삭제할 번호 입력

사용예시:
- --- [1] 메모 목록 [2] 메모 작성 [3] 메모 삭제 [4] 종료 ---
- 선택: 2
- 메모 내용: 파이썬 프로젝트 아이디어 구상하기

결과:
- --- [1] 메모 목록 [2] 메모 작성 [3] 메모 삭제 [4] 종료 ---
- 선택: 1
- 1. 파이썬 프로젝트 아이디어 구상하기

요구사항
- Python 3.x
- 추가 라이브러리 없음 (표준 라이브러리 `json`, `os`만 사용)
